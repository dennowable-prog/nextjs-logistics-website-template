# Техническая спецификация: Редизайн и оптимизация

**Проект:** New Line Cargo — сайт транспортно-логистической компании
**Стек:** Next.js 15 (Pages Router), Bootstrap 5.3, SCSS, Static Export (Cloudflare Pages)
**Визуальный вектор:** Modern Industrial / Минимализм (стиль премиальных b2b-платформ)

---

## 1. Визуальный стиль и айдентика

Главный принцип — «много воздуха», идеальная геометрия, полное отсутствие нейросетевого глянца, дыма и лишнего неона.

- **Фон:** Чистый, глубокий матовый тёмный (графит/антрацит). Полный отказ от фонового визуального шума (абстрактных сеток, светящихся точек).
- **Типографика (перевод на `next/font`)**:
  - *Заголовки:* Inter с уменьшенным межбуквенным интервалом
  - *Данные и плашки:* JetBrains Mono или Space Mono для цифр, дат, координат, трек-номеров
- **Иконки:** Полное удаление легаси-шрифта Unicons. Перенос всех иконок в кастомный `Icons.jsx` строго в формате чистых SVG.

### Дополнения

- Отказ от Google Fonts `<link>` → `next/font` с `display: 'swap'` и fallback-ами для исключения CLS
- Spline-модель на Hero — принимаем нагрузку от WebGL-рантайма. Убедиться, что `.splinecode` файлы корректно подтягиваются при статическом экспорте

## 2. Интерактив и Анимации

### Hero-блок
- 3D-модель морского контейнера через `@splinetool/react-spline`
- Модель реагирует на движение курсора (микро-наклон/вращение)
- Крупный текстовый заголовок, 2 строки описания, 1 контрастная кнопка

### Скролл-анимации (scrollCue)
- Замена однообразного `fadeIn` на разнообразные:
  - Блоки слева/справа → `slideIn` с небольшим сдвигом
  - Карточки услуг → `zoomIn`
  - Цифры/факты → `fadeInUp`
  - Каскадные задержки (delay) для последовательного появления

### Page transitions
- Лёгкий CSS-эффект `fade` при монтировании страниц без сторонних библиотек

## 3. Навигация и структура страниц

- **Sticky Header:** Оптимизация текущего (useSticky на 350px)
- **Прогресс-бар чтения:** Тонкий индикатор вверху страниц блога
- **Хлебные крошки:** Внедрить на `/services/[slug]`, `/blog/[slug]`, `/tariffs`, `/faq`
  - JSON-LD разметка для BreadcrumbList schema.org
- **Мобильное меню:** Стилизация Bootstrap offcanvas под минималистичную концепцию

---

## 4. Скорость и Оптимизация

- **Шрифты (next/font):** Inter + JetBrains Mono (или Space Mono) — локально, без внешних запросов
- **Изображения:**
  - `loading="lazy"` всем изображениям ниже fold'а
  - `width`/`height` или `aspect-ratio` на каждом изображении для предотвращения CLS

---

## 5. Админ-панель (B + A связка)

**B — Telegram (уже работает):**
- Заявки с форм летят в Telegram-чат через `telegramService.js`
- Уведомления о новых заявках

**A — Google Sheets backend:**
- Google Apps Script webhook, принимающий POST и пишущий в таблицу
- Листы: `заявки`, `tracking`, `контакты`
- Вызов вебхука из `/api/send-email.js`

**Админ-страница `/admin`:**
- Простой пароль-гейт (env var + sessionStorage)
- Сводка: количество заявок сегодня / всего
- Кнопки: «Открыть Google Sheets», «Яндекс.Метрика», «Google Analytics»
- Данные читаются через опубликованный JSON из Google Sheets
